# Zync Trader Journal

On-chain trading journal for tracking crypto trades and profit/loss transparently using Stellar.

---

## Problem

A crypto trader in the Philippines struggles to track trades across platforms, leading to inaccurate PnL and costly financial mistakes.

## Solution

Zync Trader Journal logs trades on-chain using Soroban, enabling immutable tracking, real-time PnL calculation, and optional XLM-based rewards.

---

## Timeline

Day 1–2: Smart contract development
